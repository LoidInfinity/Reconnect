# 安全说明

本程序会读取并操作 Windows 的 Wi-Fi 配置，而 **SSID / 配置文件名称完全由外部环境决定**，可能包含引号、分号、换行、ANSI 转义或双向文本控制符。下面说明我们如何对待这些输入，以及哪些风险不在本程序能处理的范围内。

## 信任边界

视为不可信输入的内容：

- Wi-Fi 的 SSID / 已保存配置名（可能由攻击者广播或伪造）；
- 网卡名称（本机可被重命名）；
- `netsh` / PowerShell 命令的文本输出；
- 配置文件中的名称、网卡、检测列表。

## 已实施的防护

| 面 | 措施 |
| --- | --- |
| 命令执行 | 所有外部命令使用 `subprocess` 的**参数列表 + `shell=False`**，从不经过 `cmd.exe` 或字符串拼接；SSID 永远只是单个参数。 |
| PowerShell | 不再把变量拼进脚本。重置有线网卡时，网卡名通过环境变量 `NG_ADAPTER_NAME` 传入，脚本本身是固定文本，引号/分号无法变成代码。 |
| 名称过滤 | 含控制字符或格式字符（换行、ESC、双向覆盖 `U+202E` 等）的配置名一律**不参与重连**；日志展示统一经过 `display_name()` 清洗。 |
| 单行文件 | 状态文件、`config/hidden_wifi.txt` 写入前拒绝含换行的名称，避免被注入额外记录。 |
| 日志 | `SafeFormatter` 去除 ANSI 转义与 `\r`；SSID / BSSID / MAC 脱敏，Wi-Fi 配置名以 `<profile:xxxx>` 伪名记录（可关联、不泄露名称），防止日志伪造与终端控制。 |
| 配置校验 | 网卡名、首选/禁用名单、DNS 重置网卡列表出现控制字符时直接拒绝保存。 |
| 安装包 | 清“下载标记”改用 Inno Setup 的 `[Code]` + `DeleteFile` 删除 `:Zone.Identifier` 数据流，**不再用 PowerShell 拼接安装路径**，路径中的引号无法注入脚本。 |
| 更新检查 | 只读取 GitHub Release 的版本号并用浏览器打开官方 Release 页，不下载、不执行任何更新内容。 |

## 残余风险（程序无法消除）

- **同名热点 / 邪恶双胞胎**：程序按配置名重连，无法验证对面 AP 的真实身份。WPA2/WPA3/802.1X 的认证由 Windows 与网络侧完成；**开放网络（无密码，例如部分校园网）最容易被同名伪造**，敏感操作建议配合 VPN 或改用有认证的网络。
- **已保存的开放网络**：如果配置文件对应开放网络，系统会接受任何同名 AP。请定期清理不需要的配置，或删除后重新连接可信 AP。
- **本地管理员**：能以管理员权限运行的程序本身就能改网卡与代理；请只从官方 Release 下载，并用 `.sha256` 校验。
- **未签名程序**：首次运行可能触发 SmartScreen；这不代表文件被篡改，请以 SHA-256 与 Release 页为准。
- **Wi-Fi 密码**：程序不读取也不保存 Wi-Fi 密码；删除/隐藏操作都不会改动 Windows 中的凭据（“从列表移除”仅隐藏显示）。
